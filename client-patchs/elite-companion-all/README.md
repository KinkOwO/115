# 累计 R3 精锐同伴补丁源码

导入正式累计 R3 的现有源码与取证头文件，未扩展钩子或重新定义协议。该冻结补丁用于客户端原生同伴资格、加载、房间和生命周期适配；仅服务端源码不能替代这些既有客户端调用点。

构建前设置 `VCVARS64` 指向 MSVC x64 环境脚本；默认支持 Visual Studio 2019 Community。使用可移植 SDK 时另设 `US115_SDK_ROOT`，可选 `US115_SDK_VERSION`，再运行 `build.cmd`。构建产物与机制自测程序位于未跟踪的 `dist/`。

默认不安装、不启用、不分发生成 DLL。运行时必须匹配冻结版本的客户端现场字节与资源身份；不匹配时沿用原有拒绝逻辑。此提交没有进行新实机验收，也没有修改游戏 EXE。日志规则与所有客户端补丁约束沿用仓库 `client-patchs/AGENTS.md`。
