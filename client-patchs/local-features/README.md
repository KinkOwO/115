# 累计 R3 本地功能补丁源码

导入 R3 已有活动界面、背包、徽章、符文等原生界面适配源码。服务端事务与奖励仍由 Go 执行；客户端部分承担冻结版本中已有的界面与交互适配，不新增玩法内容。

构建环境同 `../elite-companion-all/README.md`。`build.cmd` 编译 DLL，并执行协议互通与符文页生命周期测试；可传入另一份协议测试向量路径。`build-resource-guard.cmd` 仅编译整合资源保护测试程序。产物留在 `dist/`，不入库。

默认不安装或启用 DLL。本次未启动游戏、未改游戏 EXE、未进行新实机验收；上线应继续核对冻结客户端资源与既有安装/回滚流程。根及本目录 AGENTS 约束全部适用。
