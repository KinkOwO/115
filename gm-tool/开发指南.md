# DNF 115us GM 工具 — 开发指南

## 一、技术架构

```
浏览器 (index.html SPA)
    ↓ HTTP :28081
Python 代理 (gm_dashboard_proxy.py)
    ↓ 转发 / 直写 PG
Go GM 后端 (gmweb.exe :28080) ← 只读数据
PostgreSQL (:25438)
```

### 三层职责

| 层 | 文件 | 端口 | 职责 |
|---|---|---|---|
| 前端 | `dashboard/index.html` | — | 单文件 SPA，所有 UI 和交互 |
| Python 代理 | `dashboard/gm_dashboard_proxy.py` | 28081 | 路由分发、直写 PG、自定义业务逻辑 |
| Go 后端 | `bin/gmweb.exe` | 28080 | 只读查询、物品索引、套装目录 |

## 三、开发流程

### 3.1 修改代码

**必须用 Python 脚本修改**（文件是 UTF-8 BOM + CRLF）：

```python
p = r'D:\115us\gm-tool\dashboard\index.html'  # 或 gm_dashboard_proxy.py
raw = open(p, 'rb').read()
has_bom = raw[:3] == b'\xef\xbb\xbf'
t = raw.decode('utf-8-sig').replace('\r\n', '\n')

# 做字符串替换
old = '''...'''
new = '''...'''
assert old in t, "anchor not found"
t = t.replace(old, new)

t = t.replace('\n', '\r\n')
out = t.encode('utf-8')
if has_bom:
    out = b'\xef\xbb\xbf' + out
open(p, 'wb').write(out)
```

### 3.2 新增后端端点

1. 在 `gm_dashboard_proxy.py` 写函数：
```python
def my_feature(payload):
    # 读 payload 参数
    cid = int(payload.get("character") or 0)
    # 用 psql() 执行 SQL
    row = psql("SELECT ... FROM ... WHERE id=%d" % cid)
    return {"message": "成功", "data": row}
```

2. 在 `do_POST` 白名单加路径：
```python
if path in (..., "/api/my/feature"):
```

3. 在路由分发加：
```python
elif path == "/api/my/feature":
    self._json_ok(my_feature(payload))
```

### 3.3 新增前端 UI

1. 在对应视图函数（如 `renderServerView()`）加 HTML 字符串
2. 用 `api("/api/my/feature", {method:"POST", body:{...}})` 调后端
3. 用 `toast()` 提示结果

### 3.4 重启代理

修改 proxy 后必须重启：
```powershell
Get-Process python | Where-Object { $_.CommandLine -match 'gm_dashboard_proxy' } | Stop-Process -Force
Start-Process 'D:\115us\tools\python\python.exe' 'D:\115us\gm-tool\dashboard\gm_dashboard_proxy.py'
```

前端只需要浏览器 Ctrl+F5 刷新。

## 五、已知限制

- **装备强化**：181 字节 Record 二进制，服务端只透传不解析偏移
- **游戏内收邮件**：gm_mail 表服务端不读，客户端邮箱转圈
- **宠物**：creature 槽位无 wearSlot，服务端不支持
- **聊天/广播**：无聊天协议，无法全服发消息
- **psql() 错误处理**：returncode 不可靠，关键操作需验证结果
