# DNF 115us GM 工具 — 使用说明

## 启动方式

1. 双击「GM管理台.cmd」启动
2. 浏览器自动打开 http://127.0.0.1:28081
3. 选择账号 → 选择角色 → 开始操作

## 功能说明

### 账号管理

| 功能 | 操作 |
|---|---|
| 选择账号 | 点账号列表中的「设为当前」 |
| 克隆账号 | 输入新账号名，复制所有角色和点券 |
| 删除账号 | 危险操作，不可恢复 |
| 发放金币/点券 | 填数量 → 执行发放 |
| 技能点修改 | SP/TP 直接改数值或点重算 |

### 角色管理

| 功能 | 操作 |
|---|---|
| 选择角色 | 下拉框选择 |
| 改等级 | 填等级 → 执行（需小退重登生效） |
| 改名 | 输入新名字（仅中英文数字）→ 改名 |
| 克隆角色 | 输入新角色名，完整复制数据 |
| 删除角色 | 软删除，不可恢复 |
| 称号发放 | 输入称号 template ID → 穿戴到 slot=13 |

### 疲劳值

- **查看**：自动显示当前/上限
- **补满**：点「补满疲劳」按钮，即时生效

### 背包装备

| 功能 | 操作 |
|---|---|
| 查看穿戴 | 已穿戴装备自动显示 |
| 改数量 | 改 items 行数量，0=删除 |
| 改耐久 | 改 equipment/worn 行耐久 |
| 整理背包 | 重新排列消耗品槽位（不动装备槽） |
| 保存修改 | 改完后点「保存修改」 |

### 装备套装

1. 选职业和甲种
2. 类别筛选（防具/首饰/特殊/混合/核心）
3. 左侧选套装 → 右侧选部位
4. 点「发放到背包」或「发放到仓库」

### 服务器控制

- **连接状态**：gmweb 健康检查
- **数据库统计**：角色数、账号数、点券总量
- **日志查看器**：选 Proxy/GMWeb/PG 日志 → 刷新

### 邮件系统

- 邮件列表：查看已发邮件
- 物品发放：支持发到背包/仓库/邮箱

## 注意事项

1. **改完数据必须小退重登**才能看到效果
2. **删除操作不可恢复**，执行前确认
3. **不要改 worn 槽位号**（12-25），会导致进不去游戏
4. **角色名只能用中英文数字**，不能有符号下划线
5. **装备强化暂不支持**，按钮已禁用

## 端口一览

| 服务 | 端口 |
|---|---|
| 前端代理 | 28081 |
| Go GM 后端 | 28080 |
| PostgreSQL | 25438 |
| Redis | 26388 |

## 故障排查

| 问题 | 解决 |
|---|---|
| 页面空白 | Ctrl+F5 强制刷新 |
| API 报错 404 | 重启 GM 工具 |
| 改了不生效 | 小退重登游戏 |
| 卡在选人界面 | 检查 worn/equipment 槽位号是否正确 |
| 背包物品消失 | 从备份恢复或手动加回 |
