## 一、安装（自动备份 + 更新）

1. 把本压缩包**解压到游戏根目录**（即包含 `scripts\启动游戏.cmd`、`server\` 的那个目录），
   解压后会生成一个 {{PACKAGE_NAME}} 文件夹。
2. 进入该文件夹，双击 **`安装增量更新.cmd`**。
3. 脚本会先打印目标目录和逐文件预检结果，确认目录正确后回车（若默认目录不是游戏根目录，直接输入完整路径）。
4. 之后脚本自动完成：**备份原文件 → 写入增量文件（逐个 SHA256 校验）→ 输出结果**。

> 若目标文件与更新基线不一致（本机版本更新或手工改过），脚本会提示并等待确认，原文件同样先备份。

命令行等价用法（可在任意目录执行）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<解压目录>\_update\update.ps1" -Mode Apply -Target "C:\Game\dof\115us\115"
```

可选参数：`-Yes`（跳过确认，静默）、`-Force`（忽略基线不一致直接覆盖）、`-DryRun`（只预检不写盘）。

## 二、一键还原

双击 **`还原上一版本.cmd`** 即可把**最近一次**更新回滚：

- 更新前已存在的文件 → 从备份复制回去（并校验 SHA256）；
- 更新时新增的文件 → 删除；
- 更新时删除的文件 → 从备份恢复。

命令行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<解压目录>\_update\update.ps1" -Mode Restore -Target "C:\Game\dof\115us\115"
# 指定某一次备份：-Backup 20261004-180000_f07aa402
# 只看不动：-DryRun     确认还原：-Yes
```

查看历史备份：双击 **`查看备份记录.cmd`**，或 `-Mode List`。

## 三、备份位置

安装时会把本次涉及的每个原文件原样备份到：

```
<游戏根目录>\_update-backup\<时间戳>_<提交短号>\
    journal.json          本次改动的逐文件记录（还原依据）
    files\<仓库相对路径>   原文件备份
    result.json           安装结果
    restored.txt          已还原标记（还原成功后生成）
    rolled-back.txt       安装失败自动回滚标记（安装失败且已回滚时生成）
```

该目录保留全部历史备份，可反复还原；确认不需要后手动删除即可。
即使解压出来的更新包文件夹被删掉，只要 `_update-backup` 还在，就仍能一键还原。

## 五、注意事项

- 安装/还原只影响上表列出的文件，其余文件、`tools/` 环境、`runtime/` 数据与数据库存档均不动。

- 需要 Windows PowerShell 5.1 或 PowerShell 7+（系统自带即可）。
