# 配套客户端修改

这里附的是现用弓箭手技能页的原始脚本补丁 `archer_sp.co.patched.bin`，不是可直接拷入资源目录即可生效的完整客户端。需要通过PVF工具放入原路径并重新包装，或直接由项目提供者复制完整、已经能运行的 `work/dfo_probe_client`。

`wrapper-manifest.json` 来自最新资源构建记录，含旧机器路径，仅供追溯。当前实际配套文件以根目录 `client-requirements.json` 的哈希为准。

历史 `reference/analysis-tools/archer_layout35.py`、`archer_layout37.py` 不是当前24格版本的权威生成器，不要直接执行并覆盖最新资源。当前原始补丁已附在本目录，完整PVF不包含在源码包中。

血量还涉及客户端EXE改动：历史 `_hppatch.py` 描述在147220f48跳过缩放的补丁。它含原机路径，只供读取理解，不能对任意版本客户端执行。原始客户端应保留，当前补丁也不能视为官方数值规则恢复。
