# 115US 原生 GM 工作台

单机版与联网服主版分别构建，当前桌面界面版本 1.4.3。两版使用独立入口、连接和存档，不提供运行时切换版本。右上三个按钮固定横排，避免小窗口下被目标栏遮挡。

2026-10-08 远程控制器 1.3.0 已部署，本机 HTTPS 认证和证书 pin 检查通过。联网版默认打开「玩家列表」，开服期间即可只读查看全部账号和角色、搜索名字、双击选择；没有角色的账号也显示。等级来自最近保存的角色状态，列表不是实时在线名单。所有玩家退出后，由服主点击「进入维护」修改存档，完成后「恢复开服」。状态中的连接数是 TCP 游戏连接数，不是独立玩家计数。

状态每 3.5 秒在后台刷新，玩家目录最多每 15 秒刷新一次，未变化时不重绘列表；自动刷新不切换按钮 Enabled 状态，消除黄色按钮周期闪烁。人工操作仍串行执行、防重复点击，并等待正在进行的后台读取。云端玩家目录通过 `/control/players` 提供，仅接受服主认证后的 GET，读取固定云服 SQLite 的只读事务，包含实时 WAL，不迁移或写入存档。

联网版自动读取当前 Windows 用户 `%LOCALAPPDATA%\115US\GM\owner.dpapi`，缺失或损坏时尝试同一用户 `%APPDATA%\115US\GM\owner.dpapi` 并恢复。两处均使用 CurrentUser DPAPI；不会扫描服务端 JSON、其他 Windows 用户或游戏存档，也不再弹出选文件窗口。首次安装仍须由安装流程配置服主凭据；缺失或无法解密时直接显示原因。

## 构建

在模块根目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/gm-desktop/Build.ps1 -Backend <已验证的本机GM后端.exe> -Output <产物目录>
```

脚本使用 Windows 自带 .NET Framework C# 编译器，生成两个独立 EXE 和构建用图标。两版均嵌入已验证的本机后端：单机版用于本机服务；联网版仅使用其中的只读物品图标子命令，管理请求仍发往独立 HTTPS 控制器。服主凭据保存在当前 Windows 用户的 DPAPI 文件内，不编入程序。

## 有限预览与检查

- `--preview`：演示账号和背包，禁用所有服务请求与写操作；图标从本地 115 客户端资源只读获取。
- `--self-check <结果.json>`：检查版本、内嵌后端或服主凭据保护状态，不打开玩家库。
- `--export-design <输出目录>`：以隐藏的预览窗口渲染单机 10 页、联网 11 页，分别输出 1380×940 和 1120×720 PNG；同时输出 `render.json`。只渲染自己的控件，不截取桌面，不发送系统输入，不请求服务 API，不打开玩家库。失败时生成 `render-error.txt`，验收须同时核对无该文件、清单与对应的 20/22 张 PNG。
- `RefreshCheck.cs`：有限回归检查，单独编译 `/main:RefreshCheck /define:CLOUD`，不进入发行 EXE；验证后台刷新按钮状态、前台互斥和玩家目录解析/筛选/选择，不显示窗口、不访问真实凭据或玩家库。

实际 GM 写入继续使用原有后端校验、维护/租约、备份、审计、修订与幂等能力。UI 预览不表示真实账号修改或云端部署已经验收。
