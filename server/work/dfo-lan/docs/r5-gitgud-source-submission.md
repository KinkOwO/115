# 正式累计 R5 源码评审说明

来源为正式发布 `2026.10.11-cumulative-r5`，GUI 版本 2.0.5.0。R5 已交付并安装；本源码提交目录按该冻结源准备，替代此前尚未提交的 R3 方案。

## 范围

包含累计 R3 的角色券扩容、精锐全副本、莉尔文 NPC、在线/十日/拾光活动及原有 R2 功能；保留 R4 的称号簿 C2423 准备后恢复、签到路径与角色券 cwd 修正。R5 新增武器幻化道具/模具、皮肤登记、背包/邮件/账号金库事务与选角/城镇/副本同步，默认动画插件版本白名单与 16 GiB 客户端进程组内存配置。服务端上限仍为 4 GiB。

`launcher/` 是 R5 GUI 与内嵌 GM 源码。客户端补丁源码含既有精锐/本地功能与 R5 冻结的 `weapon-skin-animation-r1`；该补丁只在有效幻化的视觉范围排除武器装扮动画读取，不改装备或属性。提交源码及机制自测，不安装 DLL 或启动游戏。

## 可复现整理

Go 生产逻辑保持正式 R5 原字节。登录投影测试只将既有 56 字节向量从运行目录移到 testdata，并调整一处读取路径。客户端补丁既有取证头归位 src；构建脚本支持 VCVARS64、US115_SDK_ROOT、US115_SDK_VERSION，产物仅输出忽略的 dist。本地功能协议测试保留既有 167 字节 Go/C++ 互通输入。

武器插件的精确期望字节、原生循环与客户端身份记录保存于 src。generate-evidence.py 需显式 --client 提供完全匹配的客户端，只用于重新取证；常规 build.cmd 直接使用冻结头与既有机制自测。旧 validate-mod.py 为历史验证脚本，依赖原安装与工具路径，不能作为干净检出的通用验证入口；本次未运行该脚本。

scripts/r5-update 保存正式 R5 安装器、mod 升级政策、维护脚本与发布清单。二进制、PVF/密钥、资源 payload 未放进源码仓库，不能只凭这些源码清单执行安装。scripts/r3-resource-plans 与 r3-optional-input 保留作为累计沿用的资源重建计划和可选输入源码。资源编辑器需显式 -EditorDll。

不上传玩家数据库、运行日志、缓存、生成 exe/DLL、完整游戏资源或新增超过 5 MiB 的导出物。原有配置在本源码方案中保留供评审；部分配置仍有现有消费者，不能宣称所有 PVF 重复规则已清理。
