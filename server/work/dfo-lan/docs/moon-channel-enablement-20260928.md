# 沉月湖频道开启说明 — 2026-09-28

> 配套：moon-solo 贡献流（32 文件）+ 沉月湖多人共享 run（moon_party.go）。
> 本文说明频道如何开启、配置在哪、实机验收怎么走。

## 一、改了什么

1. **频道行**（`configs/channel.local34.json`）：新增 `ID 120 / Name "Moon Lake" / Type 101 / Area "[none]"`。
   Type 101 = 补丁作者实证的月湖频道 online type（网关会把该频道 CMD1 的在线类型改写为 101）。
   与军团 119 同理：源 channel_info.etc 最大 Type 只有 6，内容频道由服务端供给。
   Area [none]：流程经登录投影直接落 215（星散庇护所），不走城镇门列表。
2. **moon 配置**（`configs/moon-solo.local.json`）：频道 120、`party_capacity` 2、测试次数 255、
   入口 215/1 (784,341)（世界导出可行走矩形 [34,241,1500,200] 内）、奖励源 checksum
   `7ef2db59…d88e80`（与 dungeons.full/loot.level150/world.generated 同代）、
   奖励暂定 1 抽 × 10362432（Merchant Guild Silver Coin，[material] 可堆叠）。
   这是验收用最小奖池；运营扩池按 [踩坑记录] 的 80/20 均分规则自行调整。
3. **启动入口**（`server/启动游戏-沉月湖.cmd`）：设置 `DFO_MOON_SOLO_CONFIG` 并以
   `--source-build` 启动（归档 39 版不认识 `-moon-solo-config`）。
   `channel_probe.py` 增加了该环境变量的挂载与存在性校验。
4. **白名单**（前一批）：CMD 1722/1723 已加入全量解密采样。

  代码只接受已核验的版本集；`2.38.3.25`（补丁作者证据版）已接受，

## 三、版本核验门（已通过，2026-09-28）

补丁的协议证据来自捐赠者的 2.38.3.25 客户端；本机部署是 2.38.2.34。
按补丁作者要求「旧客户端需要维护者核验读包点之后再增加配置档；不要直接删除版本检查」。

**核验方法与结果**：从 2.38.3.25 数据库（`E:\115us\DFO.exe.i64`，输入即捐赠者客户端）
导出六个被引用的月湖读包函数原始字节（`E:\115us\ida-work\moon-readers-325\`），
与本机 `client/DFO.exe`（2.38.2.34，md5 c48cdd75…）做 64 字节滑动窗口比对（步长16）：

| 函数 | 大小 | 窗口数 | 命中 |
| --- | --- | --- | --- |
| N9 名册双mode（1452F4413 所在函数） | 28,156 B | 1,756 | **100%** |
| N2622 投影（1401B70A0） | 490 B | 27 | **100%** |
| N2281 直移（1452ACAA0） | 5,950 B | 368 | **100%** |

`configs/moon-solo.local.json` 声明 `2.38.2.34`，频道 120 可启动。

## 四、实机验收清单（容量 2）

前置：`启动游戏-沉月湖.cmd`（管理员），两个客户端分别登录（当前单账号——
第二个客户端选**另一个角色**；同一角色双登录无防重入守卫，会互相顶号）。

1. 选角进城 → 频道列表应出现 Moon Lake（若 101 不列出，回退候选：28/33，
   见 channel.local34.json CompatibilityNote 的双门说明）→ 进入月湖频道。
2. 两个角色都在 215 等候区（TCP hub 应互见）。
3. 角色A按 C12 建队（容量2）；角色B按 C12 补位（同频道先满先补）。
4. 角色A（队长）点 NPC 开始（C2284）→ 三秒后两角色同进入一层，
   N9 名册各自单形（已知边界：队伍 UI 每人只显示自己）。
5. 双方各自 C37 → 全员加载后 N2194 动态怪同时出现。
6. 交替打怪/换房：谁先进门谁驱动（对方收到同步 N29）；二层洞口同理。
7. 击杀最终 Boss → 双方各自收到 N2622 phase3 + N31。
8. 双方各自 C46 → 3 秒后各自 N35 → 各自翻牌领取 → 各自回城。
9. 边界：一方 C13 离队/断线，另一方继续（45 秒屏障超时各自撤退）；
   队长离队后队长移交下一位。
10. 事后核对 events.jsonl 的 moon_* 事件与 moon-clear:/moon-grant: 收据。
