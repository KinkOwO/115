- R7 GUI 2.0.7.0、Go 启动器和网关把发行组件、PVF 与角色策略哈希差异记录为告警后继续。运行时使用实际解析的源身份；审计默认严格，派生缓存、资源解析、存档契约、schema、安装载荷与回退校验仍独立执行。

- 上游新随机属性嵌套编码与已有装扮外观、宠物实例键保护合并，移除对应已被原生 reader 消费区域的旧拒绝检查，仍拒绝未支持的特殊属性分支；保留双方协议测试。登录保活及延迟发送绑定连接关闭，同时保留 R5 无输出时的伊斯 pending 恢复。请求采样白名单同时保留上游 2333 与 R6 2420/2421。mod 加载器保留上游干净空注册。
