## 来源与执行链

bakal.etc PHASE / RAID PHASE OF HARDMODE的每对TRIGGER/BEHAVIOR，编译为catalog.BakalScriptEvent。编译器校验完整指令和操作数；不只取其中一个动作。原类型投影仍用于审计、既有结算接口和小型测试输入，真实归档的事件执行不再用INIT预留列表代替后续规则。

解释器在同一串行连接上执行IF、符号变化、进入/退出DGN、DGN状态变化、计时器到期；支持SET（含减法）、SUB MAX、CREATE/DELETE/MOVE、RESERVE CREATE/DELETE、CREATE RANDOM、AWAKE RANDOM DRAGON、源业火增长、DGN开闭、指挥官库存、回营/终局动作。

延期任务和计时器按原到期时间处理，避免一次大步Tick把所有周期重设为当前时刻。随机觉醒候选排除已觉醒、HP0和已预约龙；首次门将进入变量保持，换房不会重新预约。普通0/900/1800秒和困难0/0/0分别来自各自源分支。

创建、删除、移动操作维护同一位置清单和IS EXIST符号。实际源CREATE才撤销位置死亡抑制；删除取消所属位置计时器。MOVE MONSTER本身定义路线，MOVABLE LOCATION是玩家导航，不能用后者拒绝进攻怪。已击杀记录独立于DGN关闭状态，关闭不能抹掉击杀计数。

事件运行先克隆可变状态，成功后提交；失败保留原状态/队列并记录bakal_source_event_pending。级联和积压有边界，防止坏脚本死循环。首领死亡依旧来自已注册源实体CMD39，事件解释器不把战报当死亡。
