- 折叠MD5：`146d73a70 ->1456b9700 ->1401be160 ->146d95230`，只对原客户端指定命令、1..400字节语义体附加；更长体不附加。外层帧校验仍保留。工具 `request_digest_oracle.py` 对真实28/46样本执行原函数。
