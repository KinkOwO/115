# 塔功能工作分支（WIP，2026-09-27）

分支：`codex/towers-wip`。这里集中保存当前已实现的塔功能和取证记录，**尚未完成，也不是已确认基线**。后续实机由玩家手动运行。

## 当前范围

- 悲叹之塔：100 层来源覆盖层、入场映射、账号进度迁移与每塔独立进度、结算及已验证的 NOTI1255 候选路径。结算时保存已有经验；通用物品发奖接口支持按已核验配置入账，但目前悲叹覆盖层没有可核实的物品 ID/数量，因此不会凭空发 Old Gold Coin。
- 迷眩之塔：33 个遭遇副本与 56 张地图的入场/换房覆盖层已完成，玩家已确认可以进图、击败 Boss 并显示普通结算。专属周进度、随机遭遇、专属奖励和通知流程仍待取证。
- 通用塔进度：按 `tower_key` 分别保存账号楼层、当日入场日期及次数。旧悲叹记录迁移保留原表，不改角色存档。仅经验证并附加 `TowerRuntime` 的塔使用这一路径；迷眩之塔尚未接入。

## 测试期临时设置

所有已接入 `TowerRuntime` 的塔暂时**不执行每日入场次数上限**，以便连续实机测试。每次入场仍按塔记录日期和次数；楼层仍只能顺序推进，满层仍拒绝入场。恢复原版每日限制前须完成实机验证并恢复入口及数据库预留操作中的上限检查。迷眩之塔目前没有对应的服务端次数门禁，客户端自身 UI 限制仍可能存在。
