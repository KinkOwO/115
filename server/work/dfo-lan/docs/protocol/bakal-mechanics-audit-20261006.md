## 免疫与增益

普通模式源buff：三龙各自领域免疫480秒，AllDragonImmune300秒，领主特攻360秒。免疫/增伤是队伍状态，不等同于N2288的五种指挥官技能库存。困难模式免疫另有360/240秒定义，不能混用攻略或普通模式数字。

同源怪物奖励池：邪龙区swan/blona在冰龙、狂龙免疫中按500000/500000选择；冰龙区steich/gerda在邪龙、狂龙免疫中选择；狂龙区eclair/nympha在邪龙、冰龙免疫中选择。BUFF CHECK将固定怪与门将配对，避免把两次奖励完全独立抽取。ADDITIONAL BUFF LIST还定义特攻/其它增益；各怪物列表不同，不能统一给一套BUFF。

当前缺口：catalog.BakalRaidMonster只保留模板/位置，丢弃BUFF COUNT、BUFF CHECK、奖励池等；没有加载bakalbuff.cos领域定义。GrantHook只在测试赋值，生产未接线。UseRaidBuff只扣计数；没有完整效果、冷却、使用入口闭环。

最新162624会话41次N2285队伍状态的20个BUFF位全部为无有效BUFF状态。官服抓包198次N2285中152次有非空BUFF对（固定记录logical173B；采集明文为192B，仅解释已确认的字段），能看到kind与到期Unix时间，因此当前缺口是授予/状态同步，不是单纯隐藏图标。

额外门禁：官服N2286波次创建的三尾字节有实际值，例如斯万07/08/19、司特茨05/09/19、埃可莱尔05/0a/19；当前统一ffffff。客户端142543160读取这三字节，但完整语义/选择时机仍待闭合。不能仅根据参考实现按COS行序推导BUFF协议编号，或自行补三字节。修复需要统一完成源奖励池解析、原生枚举/字段消费、选择/授予时机、队伍归属、到期与换房同步。

困难模式是独立源分支：固定怪预约180秒等，不能套普通模式300秒。上述时序是触发后延迟；例如普通zamir首次出现为启动阶段完成后5+60秒。

当前只执行INIT的三种10秒预留创建；后续ON CHANGE SYMBOL、CHECK TIMER END、RESERVE DELETE、MOVE和逃逸惩罚未完整执行。defeatedLocations是确认击杀状态，不该阻止源事件合法再创建；仅在明确源CREATE时清理对应抑制，同时更新实体、地图和存在符号。换房立即重复生成仍是缺陷，源计时到期后的再生才是规则。

## 随机觉醒

源为首次进入门将区域且HATCHERY FIRST ENTER==0，置该变量1后执行三次AWAKE RANDOM DRAGON。普通模式延迟0、900、1800秒；困难模式0、0、0。候选必须未觉醒、HP>0且未被另一条预约选择，不能有放回抽取同一龙，也不能每次换房重新预约。

对应源计时器21/12、22/26、23/40到期时仍检查awake==0与hp>0，然后SET相应AWAKEN1。已经直接入场觉醒或被击杀的龙需要在到期再次校验。其后的ON CHANGE AWAKEN、怒气周期与离场惩罚同样依赖源事件。

当前AwakeDragonDelays仅解析/测试，没有领域执行器消费；HATCHERY FIRST ENTER及这些预约未执行。现有已确认行为是进入三龙DGN的条件觉醒和换房保持，不能等同于随机觉醒完成。
