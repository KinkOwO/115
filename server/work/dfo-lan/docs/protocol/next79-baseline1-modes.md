# 伊斯大陆基线1、两种次数模式与恢复

当前默认保持**单机无限**。停止游戏环境后双击项目根目录的模式入口，再自行启动服务端：

| 入口 | 行为 |
| --- | --- |
| `伊斯-单机无限.cmd` | 完整通关、动画结束并回待机区后恢复可挑战状态；中途退出可重新组队 |
| `伊斯-每周一次.cmd` | 每个角色每周最多完整通关一轮；不在通关后补回次数；重登、重启不能绕过记录 |
| `伊斯-恢复基线1.cmd` | 校验备份哈希，恢复已验证的原始基线1程序（默认/源码两入口），设置无限模式 |

模式仅修改 `configs/pvf-default.json` 的 `environment.DFO_ISPINS_MODE`，
取值 `unlimited` / `weekly`；其它启动策略保持，需重启服务端生效。
恢复基线1不修改玩家数据库、物品、角色任务或客户端文件，也不回滚当前源码工作区。

每周模式以**完整四阶段通关**为一次，用既有PostgreSQL `character_events`
保存角色/挑战的通关回执，未新增表或改角色JSON。每周二09:00UTC（新加坡时间17:00）
切换到新周期；入场/重新选角时同步新周界面状态。
该时间依据[美服伊斯官方规则](https://www.dfoneople.com/news/updates/3129/Ispins%2C-the-Usurped-Lands/System)。
两种模式均记录新版本下的完整通关；无限不受记录限制。若先在无限模式通关，再切到
每周模式，本周会被视为已完成；切换模式不会删除已有回执。旧基线1不写这个新账本，
升级前的通关不会从日志自动补记。

这里提供的是“一周完整通关一次”和“单机无限”的本服策略。官服另有三次入场、
按每个Boss分别消耗奖励次数等规则；当前不声称完整复刻这些规则。奖励入库/重登保持
仍保留原版本限制，不把界面领奖成功解释为新增持久化奖励逻辑。

## 新候选的额外改动

当前新程序除模式选择外，还修正选角伊斯任务资格：PVF要求任务13763，角色列表
原生28B资格区的byte11（角色资料+0x643）由该角色真实完成记录填充。未完成的角色
保持0；不改任务状态、不批量标完成。此修复和每周模式尚需实机确认。
恢复原始基线1时会一并回到修正此重新选角门禁之前的程序。
