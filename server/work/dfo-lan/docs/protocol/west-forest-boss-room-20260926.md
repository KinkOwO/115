## 根因与修复

角色 11 的实机日志显示，副本 78 的 CMD45 房间切换目标为 boss 坐标 `(3,2)`，地图 91757（`map/cataclysm/act13/78_west_forest/91757.map`）。原始怪物行包含：

```text
[fixed] [NPC] 1020 [boss]
```

`fixedMonsters` 未处理怪物行中的 `[NPC]` 选项，因而把该合法选项当成未知字段并拒绝房间切换。解析器现要求 `[NPC]` 后有一个数值参数，消费该参数并继续解析 `[boss]`。该行仍作为 boss 怪物生成，后续行的源索引不变；缺少数值参数时明确报错。
