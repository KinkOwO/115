## 会限制出入口的条件

- 所有换房要求当前房间已加载；换图请求早于37/2073完成时拒绝，不能把加载中状态放行。
- 普通相邻门遵守DGN `[move map even enemy]`。冰龙与多数门将/路线房间源值为false，活怪未清时拦门；邪龙、狂龙和本体源值为true，服务端普通相邻移动不要求清怪。此标记仅说明服务器门禁，实际客户端机关仍受自身ACT控制。
- 战后CMD2070返回要求已加载、所属raid及RoomCleared；不是活怪时任意跨格的通行证。本体二阶段切换单独检查源PROC HP阈值、HP解锁等级、第一阶段arena与实际首领实体，不要求第一阶段死亡。
- CMD2062新进图要求源状态open、未clear，恢复等待到期且角色存活；已通关三龙不能再次进入。普通房间移动和图内2070返回不套新进图的已通关门禁。
- 死亡/主动撤退恢复时间来自同源REVIVAL TIME15/30/45/60；源无惩罚回营不增加档位。死亡选择窗约10秒，随后回营恢复等待是另一时钟。
- 源本体入场计时器到期会触发无惩罚回营；怒气导致攻坚失败、最终结算也结束当前战斗。这些是源事件退场，不是房门永久锁死。
- 已击杀门将尚未源CREATE复活时，2062再次瞄准其空arena会改到普通路线，保留之前空房修复。不能无证据强造首领或出口。
