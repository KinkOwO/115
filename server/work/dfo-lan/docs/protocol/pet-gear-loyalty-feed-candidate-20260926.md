## 本轮实现

- 红、蓝、绿宠物装备按源 `[equipment type]` 放到 list 7 的 320..375；GM/任务发放、邮件领取和礼包发放分流。登录期仅将旧存档误放在普通装备栏或 list 7 低号槽的宠物装备归位，保留实例记录，使用独立事件 key。当前穿戴配置增加宠物本体和 27..29 装备槽及 32 外观槽。
- Loyalty 存入角色 `inventory` JSON 的可选字段，旧存档缺值按 100 读取。按秒累计分数，副本穿戴 -60/小时，其余状态 +10/小时；登录后从当前时间开始计，不推断离线位置。服务器定时刷新并在副本出入时切换速率，NOTI105 下发当前值。
- 到 10 时按源 `[feed]` 分类从宠物栏自动扣一份饲料并回到 100。回满 100 取自本轮待办记录，截图本身未给出恢复量，仍待实机确认。宠物栏 CMD44 手动使用也在同一角色事务中扣一份饲料并回到 100；`[creature expitem]` 不当作饲料。Loyalty 为 0 时通关不给该宠物经验。
- 未改变 PostgreSQL schema、客户端或 DLL；没有覆盖 39 版归档程序。
