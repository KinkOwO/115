## 竞拍：已实现的后端与未开放的界面

`contents/system/raidsystem/raidreward.etc` 的 RAID8普通／困难 `[STATE REWARD] bidding_item` 现单独绑定到 Bidding.Items，不混入自动通关奖励池。当前普通10337823，困难10342710。`bakal.etc` 的普通／困难竞拍数量权重沿原解析；`bakalweeklybidding.etc`新增每模式追加数量、周分组权重、每组7整数物品行。原始五个尾值保留，非零但消费语义未闭合时明确拒绝，不按猜测生成装备属性。

`BakalRewardService.FreezeBidding` 只接受本角色已提交且有资格的通关回执，校验模式／存档来源／内容身份；同一run只抽选一次，产品与计划在已有角色事件事务中冻结，重试不重抽。普通旧通关回执无hard字段按false兼容，不能据它申请困难竞拍。

`PurchaseBiddingLot`是单人竞拍的扣款／发奖基础事务，不是出价协议处理器。已冻结本角色批次、来源、开始延迟、物品和余额全部校验；金币和奖励一起提交，发奖失败不扣金币，重复回执不再扣款／发奖。保留其它角色状态，新增状态字段向后兼容，无schema迁移。该路径目前没有接到网关，也未对玩家库实际执行。
