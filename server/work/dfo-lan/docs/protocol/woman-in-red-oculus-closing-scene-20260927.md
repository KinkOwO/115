## Confirmed live baseline and generic rule

In `runtime/roles_persist_select_actor_town_world_live_detail_dungeon_manual_20260928_002612_470320_next37/events.jsonl`, the closing CMD45 at 16:30:00Z received ACK45 and NOTI29. The following CMD37 was accepted, then the server sent NOTI291 (`map_clear_quest_triggers`) and NOTI31 (`dungeon_clear_enabled`) at 16:30:01Z. The player confirmed the quest could be completed. This proves the third completion path for the Oculus scene. The client then sent CMD46, but the server refused it with `result before committed boss completion`: the CMD37 direct send loop had omitted the `completionSent` update that the normal send loop performs. That state update is fixed in this commit; reward/result behavior after it still needs a separate live confirmation. The player used CMD42 to leave the dungeon in the confirmed run.

The current implementation no longer contains Oculus quest, dungeon, map, or coordinate constants in the runtime decision. `cmd/terminalsceneimport` reads the current PVF, full dungeon catalog and quest catalog. It exports only single `[clear map]` quests whose objective is the maze's source boss room and whose final layer map starts an action with a cinematic `[CHANGE MAP]` carrying concrete positive landing coordinates. The export includes source, DGN, MAP, ACT and CMT hashes and CMT bounds; `AttachTerminalScenes` rejects a stale source or a route inconsistent with the maze. Seven source-backed routes were exported, including the confirmed Oculus route and the previously confirmed Lotus scene. Lotus keeps its separate display-boss completion path. For a terminal map without a reportable boss, the service accepts only the native CMD45 header and CMT coordinate range, requires that the objective room was visited and its killable enemies died, then reuses the final map. After its CMD37 load it records the existing map-clear evidence, sends NOTI291 and enables clear with NOTI31. No new packet format or database migration is involved. Other routes in the export have not been live-verified.

The generic rule can be rebuilt after a PVF/catalog update with `go run ./cmd/terminalsceneimport`; startup rejects a mismatched export. The regression suite covers the confirmed route, a second synthetic source route with different identifiers, source mismatch, uncleared objective, and the existing Lotus path.
