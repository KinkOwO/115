# 觉醒任务目标角色筛选确认基线（2026-09-26）

用户实机确认：Episode 列表中的觉醒任务只保留符合当前角色 job/grow 的任务。

## 原因与修复

当前 115 任务源的觉醒任务（如 21956 Omniblade、21960 Dark Lord、21976 Nen Empress）没有单独的 `[job]` 条件，使用 `[target character]` 里的三元组限定职业、转职分支和觉醒阶段。旧服务端只检查 `[job]`、`[grow type]`，因此把其他职业与分支的觉醒任务一起下发。

服务端现在解析所有 `[target character]` 行，按三元组的任意匹配判断角色；数值 `-1` 为通配值。缺少该段的任务沿用原有规则。解析不完整的段落不进入可接列表；接取入口执行同样的目标角色检查。
