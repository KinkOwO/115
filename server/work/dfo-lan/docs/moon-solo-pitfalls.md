## 协议与地图坑

1. **NPC 无开始项**：N9 内有两次 mode 赋值。只写前面27、后面保留0，
   后读字段会覆盖前读字段。单人成员99B旧简化格式也不能混进新107B基础形状。
   本补丁113B=107B基础+u32人数+每成员两项计数。
2. **建队成功不等于进图已实现**：还需要 C2284、N2622 阶段1、三秒准备、
   角色状态/资料、N9/N27/N28/N29，加载 C37 后才释放动态怪。
3. **综合次数**：N1726 是两张表的完整快照，不是加一条记录。
   普通频道/其他征讨整合时应从统一次数来源输出，不能互相清表。
4. **二房清怪断线**：先检查等级145掉落表，不只盯协议。高等级模板存在
   不代表 drop probability/gold/grade 三张表已导出。
5. **特殊怪**：N2194 动态怪进入服务端当前房间实体集合后才能接受死亡；
   不要发了客户端可见怪、却没有服务端实体。普通 N29 不能用固定索引0伪装动态怪。
6. **守门怪房**：准备好的守门怪要压住该图原固定小怪，加载完成再创建守门怪。
   本分支只有两个主题特殊怪；不能把每个主题房都强制再塞一个。
7. **一层结束不是自动切层**：等待挖洞/靠近入口的 C2062。只接受当前已完成守门怪
   的第二层请求；客户端包内的坐标不是可任意传送的授权。
8. **二层带怪**：沿源路线携带存活普通怪、保留实体编号与来源坐标；
   N2194 carried 字节为1。源上限30只，不是凭印象硬定“最多四个房间”。
   最终 Boss 和未击败的特殊怪目标房有清空携带怪的门。
9. **掉不下去/出门黑屏**：普通换房也要发18B transition；其第一个字节为0
   不等于没有 transition，方向与坐标来自合法源邻接边。
10. **打死最终 Boss 不翻牌**：这里的完成证据是已注册109017558、Boss房、真实
    所属死亡 C39，不依赖普通 C117。移除这一依赖不是允许任意“已通关”请求。
11. **通关动画与翻牌**：月湖使用自己的 N2622 成功演出，之后 N35→阶段4；
    不额外混入普通 N34。发放对应保存的奖励，不把 UI 占位0/0当金币。
12. **装备 Value ≠ 数量**：29B 奖励行的 value 对装备是实例值；只发一件。
13. **回城 NPC 不可点**：阶段号与 outcome 分开。N2622+4 成功是1、失败是2；
    own actor 的城镇状态/资料恢复也必须完整。本候选加入这条修正，
    但捐赠者此前的“换频道也没恢复”现象仍需原生实测，不能写已根治。
14. **短拒绝包有风险**：C71 回完整八行33B，C72按自己的失败格式，
    C2284失败分支19B；不要随手用一字节0回复所有命令。
15. **复活规则勿混搭**：本补丁读公开端 coin，并沿用原复活消费；没有注入
    本地免费15次。金币、道具数量与复活余额是不同存储字段。

## 证据边界

编码注释记录的是捐赠者 2.38.3.25 的静态消费地址及已整理字段，不是公开端
2.38.2.34 的地址。包括：N9 1452F4413/1452F44C5 双 mode；
N2622 经1401B70A0投影且 phase3/5消费 outcome；C2062 的46B读序；
N2281 1452ACAA0；N35 1452A74C0 特殊奖励行。
提交中不复制带账号身份的官方包。维护者可据自己合法环境重新核对，
不能仅因 Go 编码长度通过就宣布旧客户端兼容。

源机制绑定于本版本 moonlake.cos 与两层 dungeon/map；源码中的
750分守门、fever/逃逸窗口、主题模板和路线不是跨版本通用常量。
PVF改了这些机制后要一起重新审核，不只是修改 checksum。

## 多人迁移（本次未实现）

不要把单人 worldSession 复制四份再同时跑各自怪物逻辑，按以下独立步骤迁移：

1. **身份和固定槽位**：建立队伍租约/连接代次、频道 context、成员固定槽与队长。
   队长离开不紧缩槽；同模板、同账号、同频道都不能替代角色连接身份。
2. **网络就绪**：接上本版本的 UDP 协调与端点学习，入队/换区分别同步。
   中继端口学到了不等于所有成员 pair 都完成握手；不把私有房间位置广播全频道。
3. **共享副本唯一 owner**：用一份 run/room/monster UID/RNG seed；
   准备与入场采用队伍快照，各成员出自己的 USERINFO/场景通知。
   C37全员屏障、超时退出、旧连接晚到要有 run+room+lease 验证。
4. **换房与特殊怪扇出**：同一状态转移只执行一次；生成不可变事件，
   向所有成员发一致的N29/N2194/N2622。慢成员不读取“后来那一房”的状态。
   两层仍同run，带怪不能按成员重复复制。
5. **每个成员结算**：冻结参与者名单，各角色独立权限/资产事务/领取收据；
   所有人结果就绪后投递各自N35与牌位，不能仅向队长发送。
   不要跨多个数据库事务假装全队原子扣费；需明确提交/补偿规则。
6. **退出和收尾**：全体撤回、单人离开、掉线、换频道分别建模；
   清理成员别名与旧回调，不删可补领奖励。移交队长不改变本局已确定随机源。

最小多人验收：2人入场/队友翻牌，3人带怪换房一致，
慢加载和断线重登，队长离队、全体回城后NPC、重复结果/满包。
在这些完成前保持容量1，不把容量数字改成4就宣布多人完成。
