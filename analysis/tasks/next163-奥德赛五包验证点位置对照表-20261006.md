## 五、④ 层图格那一格怎么认

100004968 贵族机要**进场后的第一个格子**（网格坐标 (0,2)），它的源结构是：

```
map 0 2 100015973            ← base 图（宫殿庭院，过场"之前"那间）
layered 0 2 100015974 100016356   ← 该格的层序列：先放 100015974，再进 100016356
```

所以你看到的是：**进这本 → 开场剧情过场 → 变成一间演出房**。那间就是 ④ 要验的格子。
判据是"**清完后面几间房再走回来**"，回来时背景应正常、且**不重播**开场剧情。

（`100016356` 的房间文件名是 `100016356_cc.map`，`100015974` 是 `100015974_e_scene_1.map` ——
地图文件没有 [name] 段，所以没有可显示的房名，只能按上面的位置描述认。）
